# ဘာသာစုံ အိမ်သုံးစမတ်အကူ


**အခြားဘာသာများဖြင့် ဖတ်ရန်:** [မြန်မာ](Read.my.md) · [Català](Read.ca.md) · [English](Read.en.md) · [Español](Read.es.md) · [Français](Read.fr.md) · [Deutsch](Read.de.md) · [Italiano](Read.it.md) · [Português](Read.pt.md) · [Nederlands](Read.nl.md)

ဤပရောဂျက်သည် Raspberry Pi ပေါ်တွင် ဘာသာစုံအသံအကူပါဝင်သော ဒေသတွင်း အိမ်သုံးစမတ်စနစ်တစ်ခု တည်ဆောက်ပုံကို ဖော်ပြထားသည်။

## Mina အမည်၏ မူလအစ

**Mina** သည် ရှေးဂျာမန်ဘာသာစကား အမြစ်စကားလုံး *minna* မှ ဆင်းသက်လာပြီး “မှတ်ဉာဏ်”၊ “ချစ်ခင်ဂရုစိုက်မှု” သို့မဟုတ် “အမှတ်တရ” ဟု အဓိပ္ပာယ်ရသည်။ အခြားဘာသာစကားများတွင်လည်း ဤအမည်ကို တွေ့ရသည်။ ပါရှန်ဘာသာတွင် *mīnā* သည် “အလင်းရောင်” သို့မဟုတ် “အပြာရောင်ဖန်” နှင့် ဆက်စပ်ပြီး၊ ဂျပန်ဘာသာတွင် *mina* သည် “အားလုံး” သို့မဟုတ် “အားလုံးအတူတကွ” ဟု အဓိပ္ပာယ်ရသည်။

ဤအဓိပ္ပာယ်များသည် **မျှဝေထားသော မှတ်ဉာဏ်နှင့် လူမှုအသိုင်းအဝိုင်း** ကို ကိုယ်စားပြုပြီး အိမ်၏နေ့စဉ်ဘဝတွင် အတူရှိကာ ကူညီပံ့ပိုးပေးသည့် အကူ၏တန်ဖိုးများနှင့် ကိုက်ညီသည်။

အသံထွက်အားဖြင့် Mina သည် နူးညံ့သော်လည်း ရှင်းလင်းသည်။ `Mi-na` ဟု စာလုံးစုခွဲကာ အသံထွက်ပြီး အိမ်တွင်းတွင် အသုံးများသော စကားလုံးများနှင့် ရောထွေးနိုင်ခြေ နည်းသည်။

## ရည်မှန်းချက်

မဖြစ်မနေ cloud ဝန်ဆောင်မှုများကို မှီခိုစရာမလိုဘဲ အသံအမိန့်များဖြင့် အိမ်သုံးပစ္စည်းများကို ထိန်းချုပ်နိုင်သည့် ကိုယ်ရေးကိုယ်တာလုံခြုံမှုရှိ၊ ယုံကြည်စိတ်ချရပြီး မြန်ဆန်သော အိမ်သုံးစမတ်စနစ်တစ်ခု တည်ဆောက်ရန်။

စနစ်တည်ဆောက်ပုံတွင် အောက်ပါတို့ကို ပေါင်းစပ်ထားသည်-

- အိမ်သုံးစမတ်အမိန့်များကို ဒေသတွင်းတွင် လုပ်ဆောင်၍ ကိုယ်ရေးအချက်အလက်ကို ကာကွယ်ခြင်း။
- အထွေထွေမေးခွန်းများကို Ollama ဖြင့် ဒေသတွင်းတွင် ဖြေရှင်းခြင်း။
- ရှုပ်ထွေးသောမေးခွန်းများနှင့် နောက်ဆုံးရအချက်အလက်များအတွက် cloud မော်ဒယ်များကို အသုံးပြုခြင်း။

## ဟာ့ဒ်ဝဲ

- RAM 8 GB ပါသော Raspberry Pi 5 ကို အကြံပြုသည်။ လိုက်ဖက်မှုမှာ အကန့်အသတ်ရှိပြီး Raspberry Pi 3B+ အထိသာ ပံ့ပိုးသည်။
- SD ကတ်မသုံးဘဲ NVMe SSD ကို အသုံးပြုသည်။ SD ကတ်အတွက် လိုက်ဖက်မှုမှာ အကန့်အသတ်ရှိသည်။
- အသံဖမ်းယူခြင်းနှင့် ပြန်ထုတ်ခြင်း နှစ်မျိုးလုံးလုပ်နိုင်သော USB မိုက်ခရိုဖုန်းနှင့် စပီကာ။
- Zigbee၊ Matter၊ Philips Hue သို့မဟုတ် ဒေသတွင်း Wi-Fi နှင့် လိုက်ဖက်သော အိမ်သုံးစမတ်ပစ္စည်းများ။
- အပူလွန်ကဲမှုကြောင့် အမြန်နှုန်းလျော့ကျခြင်းကို ကာကွယ်ရန် တက်ကြွအအေးပေးစနစ်။

## စနစ်တည်ဆောက်ပုံ

1. Home Assistant OS သည် ပစ္စည်းများနှင့် အလိုအလျောက်လုပ်ဆောင်မှုများကို စီမံသည်။
2. openWakeWord သည် နှိုးဆော်စကားလုံးကို ဒေသတွင်းတွင် ရှာဖွေသည်။
3. Whisper သည် Wyoming မှတစ်ဆင့် အသံအမိန့်များကို လက်ရှိအသုံးပြုနေသော ဘာသာစကားဖြင့် စာသားအဖြစ် ပြောင်းပေးသည်။
4. ရည်ရွယ်ချက်ခွဲခြမ်းစိတ်ဖြာသည့် ပရိုဆက်ဆာသည် အိမ်သုံးစမတ်အမိန့်များကို ဒေသတွင်းတွင် လုပ်ဆောင်သည်။
5. Piper သည် ကတ်တလန်ဘာသာဖြင့် အဖြေများကို အသံအဖြစ် ဖန်တီးပေးသည်။
6. Ollama သည် အချက်အလက်များကို အင်တာနက်သို့ မပို့ဘဲ အထွေထွေမေးခွန်းများကို ဖြေရှင်းသည်။
7. အဆင့်မြင့် AI လိုအပ်ကြောင်း အတိအလင်းတောင်းဆိုသော မေးခွန်းများကိုသာ cloud AI ထံ ပို့သည်။

## စီစဉ်ထားသော လုပ်ဆောင်ချက်များ

- မီးများ၊ ပလပ်ပေါက်များ၊ အပူချိန်ထိန်းစနစ်များ၊ လိုက်ကာများနှင့် အခြားပစ္စည်းများကို အသံဖြင့် ထိန်းချုပ်ခြင်း။
- ဘာသာစုံ အမည်ကွဲများ။
- အသံဖြင့် စီမံနိုင်သော အချိန်မှတ်ကိရိယာများ။
- ဒေသတွင်း မိုးလေဝသအခြေအနေကို မေးမြန်းခြင်း။
- သီချင်းဖွင့်ခြင်းနှင့် ထိန်းချုပ်ခြင်း။
- ကိုယ်ရေးလုံခြုံမှုကို ဦးစားပေးသော Ollama မော်ဒယ်သို့ ပြောင်းလဲအသုံးပြုခြင်း။
- အသံဖြင့် ပြောသူကို မှတ်မိခြင်း။
- ရေရှည် စကားဝိုင်းအကြောင်းအရာကို မှတ်သားခြင်း။
- လိုအပ်ပါက cloud AI မော်ဒယ်ထံ လွှဲပြောင်းခြင်း။
- အရန်သိမ်းခြင်းနှင့် စွမ်းဆောင်ရည်စောင့်ကြည့်ခြင်း။

## ဒီဇိုင်းအခြေခံမူများ

- အင်တာနက်မရှိသည့်အခါတွင်လည်း အိမ်သုံးစမတ်အမိန့်များ အလုပ်လုပ်ရမည်။
- ဒေသတွင်း ရည်ရွယ်ချက်ပရိုဆက်ဆာကို LLM ထက် ဦးစားပေးရမည်။
- အသံဒေတာနှင့် သီးသန့်စကားဝိုင်းများကို ဖြစ်နိုင်သမျှ ဒေသတွင်းတွင်သာ လုပ်ဆောင်ရမည်။
- cloud မော်ဒယ်များကို အတိအလင်းတောင်းဆိုထားသော သို့မဟုတ် ရှုပ်ထွေးသော မေးခွန်းများအတွက်သာ အသုံးပြုမည်ဖြစ်ပြီး၊ အကူကို စတင်သတ်မှတ်ချိန်တွင် အသုံးပြုသူက အတိအလင်း ဖွင့်ထားမှသာ အသုံးပြုမည်။
- ဆက်တိုက်ဝန်အောက်တွင်လည်း အပူချိန်နှင့် တုံ့ပြန်ချိန် တည်ငြိမ်နေရမည်။

## ပရောဂျက်အခြေအနေ

လက်ရှိတွင် ဤပရောဂျက်ကို လုပ်ဆောင်ချက်စာရင်းတစ်ခုအဖြစ် သတ်မှတ်ထားသည်။ အသုံးပြုသူဇာတ်လမ်းများ ပြီးစီးလာသည်နှင့်အမျှ အသေးစိတ်ဖွဲ့စည်းပုံများ၊ အလိုအလျောက်လုပ်ဆောင်မှုများနှင့် တပ်ဆင်အသုံးပြုရေး script များကို ထည့်သွင်းသွားမည်။
