**Inwewin:** Anishinaabemowin

Oma akiin gii-inaakonige ezhi-ayaad wiikwedong maampii Raspberry Pi, miinawaa gagwejitooying inwewinan endaso-ayaang.

## Mina izhinikaazowin ezhi-maajaad

**Mina** gii-onji-izhiwebizowin waasa Germanic inwewin *minna*, gaa-izhi-anishinaabemong «gikenimowin», «zaagi’idiwin» aaniin ge-izhi-gikendang. Aaniish naa goji inwewinan: Persian inwewin *mīnā* gii-giizhigad «waaseya» aaniin «ozhaawashkwaa wiiyaas»; Japanese inwewin *mina* gii-izhiwebad «gakina awiya» aaniin «gakina bezhigwan».

Omaa izhiwebiziwinan **gikendamowin wiiji’idiwin miinawaa gagwejitooying** gii-izhi-nisidawendam, bezhig gagwejitooying gagwejitoo wiiji-ayaad endaso-giizhigad waakaa’iganing.

Mina izhinikaazowin gii-nisidawendam, gaa-izhi-inaad: `Mi-na` niizh syllable; gaye gaa-gikendang inwewinan waakaa’iganing ezhi-ayaad, gaye gaawiin gagwejitoon.

## Aaniin ezhi-ayaad

Gii-ozhitoon wiiji-ayaad, gwayak miinawaa bibaamaadizi, gagwejitooying endaso-ayaad waakaa’iganing, inwewinan gagwejitooing, gaawiin minik cloud kichi-gikendamin.

Oma ezhi-ayaad gagwejitooying:

- Maampii ezhi-inaakonige gagwedwenan miinawaa gagwejitooying.
- Ollama maampii gikendamowin gagwedwenan endaso-ayaad.
- Cloud modelan gagwedwenan gichi-ayaad miinawaa oshki-gikendamang.

## Kii’ozhitoon

- Raspberry Pi 5 8 GB RAM gaa-inaakonige. Raspberry Pi 3B+ gagwejitoon, gwayak naawak.
- NVMe SSD, SD card gaawiin. SD card gagwejitoon gwayak naawak.
- USB mic maampii niizh-izhi-ayaad speaker.
- Zigbee, Matter, Philips Hue aaniin local Wi-Fi gagwejitoon waakaa’iganing.
- Active cooling, gaa-ozhaawashkwendang gichi-giizhigad gaawiin gagwejitoon.

## Ezhi-ozhitooying

- Domotic commands gaawiin Internet ayaang gagwejitoon.
- Local intent processor LLM gaa-ayaad gichi.
- Audio data miinawaa private conversations maampii gagwejitoon.
- Cloud models gagwedwenan explicit aaniin complex ayaad gagwejitoon, user gagwejitoo configuration gaa-inaad.
- System temperature miinawaa latency gwayak ayaad endaso-ayaad.
