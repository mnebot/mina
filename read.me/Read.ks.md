# واریاہ زبٲنۍ گھرٕچ آٹومیشن مددگار

**پَرِو:** [کاتالان](Read.ca.md) · [انگریزی](Read.en.md) · [ہسپانوی](Read.es.md) · [فرانسیسی](Read.fr.md) · [جرمن](Read.de.md) · [اطالوی](Read.it.md) · [پرتگالی](Read.pt.md) · [ڈچ](Read.nl.md)

یہ منصوبہ Raspberry Pi پیٹھ مقٲمی طور چَلان، واریاہ زبٲنۍ آواز مددگار سٲتھ گھرٕچ آٹومیشن نظام تعینات کرنُک بیان دِوان۔

## Mina ناوُک ماخذ

**Mina** ناوُک رٲژ قدیم جرمن *minna* چھُ، یُس «یاد»، «محبت» یا «یادگار» معنی دِوان۔ یہ ناو باقی زبٲنَن منز تہِ چھُ: فارسی منز *mīnā* «روشنی» یا «نیلگوں کانٛچ» سٲتھ وابستہ چھُ، تہ جاپانی منز *mina* معنی «سٲری» یا «سٲری اکھ ساتھ»۔

یہ مطلب **سانجھی یاد تہٕ برادری** ہُنٛد نشان چھِ؛ یہ قدرٕ گھرٕچ روزمرہ زندگی منز ساتھی تہٕ مدد کرن وٲل مددگار سٲتھ موزوں چھِ۔

آوازٕچ لحاظہ Mina نرم مگر واضح ناو چھُ؛ امُک تلفظ `Mi-na` چھُ، تہٕ گھرٕچ ماحولس منز عام لفظن سٲتھ غلط فہمی ہُنٛد امکان کم چھُ۔

## مقصد

اکھ نجی، بھروسہ مند تہٕ تیز گھرٕچ آٹومیشن نظام بناوُن، یُس کٲنٛسہ کلاؤڈ خدمتہٕ پیٹھ لازمی انحصار بغیر آوازٕچ حکمَن سٲتھ گھرٕچ ڈیوائس کنٹرول کرِ۔

نظامٕچ بناوٹ منز شامل چھِ:

- گھرٕچ آٹومیشن حکمَن تہٕ رازداری خٲطرٕ مقٲمی پروسیسنگ۔
- عام سوالَن خٲطرٕ Ollama سٲتھ مقٲمی مصنوعی ذہانت۔
- مُشکل سوالَن تہٕ تازہ معلومات خٲطرٕ کلاؤڈ ماڈل۔

## ہارڈویئر

- 8 GB RAM سٲتھ Raspberry Pi 5 سفارش چھُ۔ Raspberry Pi 3B+ تام محدود مطابقت۔
- SD کارڈ استعمال کرنٕ بغیر NVMe SSD۔ SD کارڈ سٲتھ محدود مطابقت۔
- دوطرفہ USB مائیکروفون تہٕ سپیکر۔
- Zigbee، Matter، Philips Hue یا مقٲمی Wi-Fi سٲتھ مطابقت رٲکھن وٲل گھرٕچ آٹومیشن ڈیوائس۔
- لگاتار استعمال دوران گرمی سٲتھ کارکردگی کم گژھن (thermal throttling) روکنہ خٲطرٕ فعال کولنگ۔

## بناوٹ

1. Home Assistant OS ڈیوائس تہٕ آٹومیشن سنبھالان۔
2. openWakeWord جگاوُن وٲل لفظ مقٲمی طور پہچانان۔
3. Wyoming ذریعہ Whisper فعال زبانس منز حکمَن تحریری متن منز بدلٲوان۔
4. انٹینٹ پروسیسر گھرٕچ آٹومیشن حکم مقٲمی طور نافذ کران۔
5. Piper کاتالان زبانس منز جواب آوازس منز بناوان۔
6. Ollama انٹرنیٹ پیٹھ کینہہ معلومات بھیژنٕہ بغیر عام سوال حل کران۔
7. صرف تِم واضح طور منتخب سوال کلاؤڈ AI کُن بھیژن یِم خٲطرٕ جدید AI ضرورت چھُ۔

## منصوبہ بند خصوصیات

- بتی، پلگ، آب و ہوا کنٹرول، پردہ تہٕ باقی ڈیوائس آواز سٲتھ کنٹرول کرُن۔
- واریاہ زبٲنۍ متبادل ناو۔
- آوازٕ ذریعہ چلن وٲل ٹائمر۔
- مقٲمی موسمی معلومات۔
- موسیقی بجاون تہٕ کنٹرول کرُن۔
- Ollama ماڈل پیٹھ نجی متبادل۔
- آوازٕ ذریعہ شخص پہچانُن۔
- طویل مدتی سیاقٕچ یادداشت۔
- اختیاری طور کلاؤڈ AI ماڈل کُن بھیژن۔
- بیک اپ تہٕ کارکردگی نگرانی۔

## ڈیزائن اصول

- انٹرنیٹ کنکشن بغیر تہِ گھرٕچ آٹومیشن حکم چلن گژھن۔
- مقٲمی انٹینٹ پروسیسرس LLM پیٹھ ترجیح مِلن گژھ۔
- آڈیو ڈیٹا تہٕ نجی گفتگو ترجیحی طور مقٲمی طور پروسیس کرن گژھن۔
- کلاؤڈ ماڈل صرف واضح یا مُشکل سوالَن خٲطرٕ استعمال کرن گژھن، تہٕ صرف تیلہ ییلہ صارف مددگار ترتیب دوان وقت واضح اجازت دِیہ۔
- لگاتار بوجھس منز تہِ نظامٕچ درجہ حرارت تہٕ تاخیر مستحکم آسٕنۍ گژھ۔

## منصوبُک حال

منصوبہ اکھ عملی کامَن ہُنٛد فہرست طور متعین چھُ۔ صارف کہانیاں مکمل گژھنہٕ سٲتھ مخصوص ترتیب، آٹومیشن تہٕ تعیناتی سکرپٹ شامل کرن یِیَن۔
