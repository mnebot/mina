# 多種語言个智能屋家助理


**閱讀版本：** [客家話](Read.hak.md) · [Català](Read.ca.md) · [English](Read.en.md) · [Español](Read.es.md) · [Français](Read.fr.md) · [Deutsch](Read.de.md) · [Italiano](Read.it.md) · [Português](Read.pt.md) · [Nederlands](Read.nl.md)

這個計畫介紹在 Raspberry Pi 頂高部署本地个智能屋家系統，還有多種語言个聲音助理。

## Mina 名字个來源

**Mina** 係從古日耳曼語根 *minna* 來个，意思係「記憶」、「關懷」抑係「回想」。這個名字在其他語言也有：波斯語个 *mīnā* 同「光」抑係「藍色玻璃」有關係；日語个 *mina* 意思係「大家」抑係「大家共下」。

這兜意思象徵**共同个記憶摎社區**，同一個陪伴、支持屋家日常生活个助理所重視个價值相合。

講著音，Mina 聲音柔和又清楚，照音節讀做 `Mi-na`，在屋家環境肚同常用詞聽毋出相像个機會較少。

## 目標

建立一個注重隱私、可靠又反應遽个智能屋家系統，分使用者用聲音命令控制屋下个設備，毋使一定依賴雲端服務。

架構包括：

- 在本地處理智能屋家命令，保護隱私。
- 用 Ollama 在本地處理一般問題。
- 用雲端模型回答較複雜个問題摎提供最新消息。

## 硬體

- 建議用 8 GB RAM 个 Raspberry Pi 5。相容性有限，最低支援到 Raspberry Pi 3B+。
- 用 NVMe SSD，毋使用 SD 卡。對 SD 卡个支援有限。
- 雙向 USB 麥克風摎喇叭。
- 相容 Zigbee、Matter、Philips Hue 抑係本地 Wi-Fi 个智能屋家設備。
- 主動散熱，避免過熱降頻。

## 架構

1. Home Assistant OS 管理設備摎自動化。
2. openWakeWord 在本地偵測喚醒詞。
3. Whisper 透過 Wyoming 將聲音命令轉成目前啟用語言个文字。
4. 意圖處理器在本地執行智能屋家命令。
5. Piper 用加泰羅尼亞語合成聲音答覆。
6. Ollama 處理一般問題，毋會摎資料傳到網際網路。
7. 只有明確需要進階 AI 个問題正會傳到雲端 AI。

## 預計功能

- 用聲音控制燈、插座、空調、百葉窗摎其他設備。
- 多種語言別名。
- 用聲音管理計時器。
- 查詢本地天時。
- 播放摎控制音樂。
- 私隱優先地改用 Ollama 模型。
- 透過聲音認出講話个人。
- 長期上下文記憶。
- 可以選擇交分雲端 AI 模型處理。
- 備份摎效能監視。

## 設計原則

- 無網際網路連線也愛做得執行智能屋家命令。
- 本地意圖處理器優先過 LLM。
- 聲音資料摎私人對話盡量在本地處理。
- 雲端模型淨用在明確提出抑係較複雜个問題，而且愛使用者設定助理時明確選擇啟用正會使用。
- 系統在長時間負載之下愛維持溫度摎延遲穩定。

## 計畫狀態

目前這個計畫用功能待辦清單來定義。詳細設定、自動化摎部署指令碼會隨使用者故事逐步完成來新增。
