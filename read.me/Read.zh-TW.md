# 多語言智慧家庭助理


**閱讀版本：** [繁體中文](Read.zh-TW.md) · [Català](Read.ca.md) · [English](Read.en.md) · [Español](Read.es.md) · [Français](Read.fr.md) · [Deutsch](Read.de.md) · [Italiano](Read.it.md) · [Português](Read.pt.md) · [Nederlands](Read.nl.md)

本專案介紹如何在 Raspberry Pi 上部署本機智慧家庭生態系統，並搭配多語言語音助理。

## Mina 名稱的由來

**Mina** 源自古日耳曼語詞根 *minna*，意思是「記憶」、「關愛」或「回憶」。這個名字也出現在其他語言中：在波斯語裡，*mīnā* 與「光」或「藍色玻璃」有關；在日語裡，*mina* 意思是「大家」或「所有人聚在一起」。

這些含義象徵著**共同記憶與社群**，與陪伴並支持家庭日常生活的助理所秉持的價值相符。

從發音來看，Mina 聽起來柔和又清楚，按音節讀作 `Mi-na`，在家庭環境中與常用詞混淆的可能性很低。

## 目標

打造一套隱私、可靠且反應迅速的智慧家庭系統，讓使用者能以語音命令控制家中裝置，而不必依賴雲端服務。

架構結合：

- 在本機處理智慧家庭命令並保障隱私。
- 使用 Ollama 在本機處理一般問題。
- 使用雲端模型回答複雜問題並提供最新資訊。

## 硬體

- 建議使用配備 8 GB RAM 的 Raspberry Pi 5。相容性有限，最低可支援至 Raspberry Pi 3B+。
- 使用 NVMe SSD，不使用 SD 卡。對 SD 卡的支援有限。
- 雙向 USB 麥克風與喇叭。
- 相容 Zigbee、Matter、Philips Hue 或本機 Wi-Fi 的智慧家庭裝置。
- 主動散熱以避免熱降頻。

## 架構

1. Home Assistant OS 管理裝置與自動化。
2. openWakeWord 在本機偵測喚醒詞。
3. Whisper 透過 Wyoming 將語音命令轉寫為目前啟用語言的文字。
4. 意圖處理器在本機執行智慧家庭命令。
5. Piper 以加泰羅尼亞語合成回覆語音。
6. Ollama 在不將資料傳送到網際網路的情況下處理一般問題。
7. 只有明確需要進階 AI 的請求才會傳送給雲端 AI。

## 預計功能

- 以語音控制燈光、插座、空調、百葉窗及其他裝置。
- 多語言別名。
- 以語音管理計時器。
- 查詢當地天氣。
- 播放與控制音樂。
- 隱私優先地改用 Ollama 模型。
- 透過聲音辨識說話者。
- 長期脈絡記憶。
- 可選擇轉交給雲端 AI 模型。
- 備份與效能監控。

## 設計原則

- 智慧家庭命令必須能在沒有網際網路連線時運作。
- 本機意圖處理器優先於 LLM。
- 音訊資料與私人對話應優先在本機處理。
- 雲端模型僅用於明確提出或較複雜的請求，而且只有在使用者設定助理時明確選擇啟用，才會使用。
- 系統在持續負載下必須維持穩定的溫度與延遲。

## 專案狀態

本專案目前以功能待辦清單的形式定義。具體設定、自動化與部署指令碼將隨著使用者故事逐步完成而陸續新增。
