# 다국어 스마트 홈 어시스턴트


**다른 언어로 읽기:** [한국어](Read.ko.md) · [Català](Read.ca.md) · [English](Read.en.md) · [Español](Read.es.md) · [Français](Read.fr.md) · [Deutsch](Read.de.md) · [Italiano](Read.it.md) · [Português](Read.pt.md) · [Nederlands](Read.nl.md)

이 프로젝트는 다국어 음성 어시스턴트를 갖춘 로컬 스마트 홈 환경을 Raspberry Pi에 구축하는 방법을 설명합니다.

## Mina라는 이름의 유래

**Mina**는 고대 게르만어 어근 *minna*에서 유래했으며, “기억”, “애정” 또는 “추억”을 뜻합니다. 다른 언어에서도 쓰이는 이름입니다. 페르시아어의 *mīnā*는 “빛” 또는 “푸른 유리”와 관련이 있고, 일본어의 *mina*는 “모두” 또는 “모두 함께”를 뜻합니다.

이러한 해석은 **공유된 기억과 공동체**를 상징하며, 가정의 일상을 함께하고 지원하는 어시스턴트의 가치와 잘 어울립니다.

발음 면에서도 Mina는 부드럽고 또렷한 이름입니다. 음절별로 `Mi-na`라고 발음하며, 가정에서 흔히 쓰는 단어와 혼동될 가능성이 낮습니다.

## 목표

클라우드 서비스에 반드시 의존하지 않고 음성 명령으로 집 안의 기기를 제어할 수 있는, 개인정보 보호를 중시하고 안정적이며 빠른 스마트 홈 시스템을 만듭니다.

아키텍처는 다음을 결합합니다.

- 스마트 홈 명령을 로컬에서 처리하여 개인정보를 보호합니다.
- Ollama를 사용해 일반적인 질문을 로컬에서 처리합니다.
- 복잡한 질문과 최신 정보에는 클라우드 모델을 사용합니다.

## 하드웨어

- 8 GB RAM이 탑재된 Raspberry Pi 5를 권장합니다. 호환성은 제한적이며 Raspberry Pi 3B+까지 지원합니다.
- SD 카드를 사용하지 않고 NVMe SSD를 사용합니다. SD 카드 호환성은 제한적입니다.
- 양방향 USB 마이크와 스피커.
- Zigbee, Matter, Philips Hue 또는 로컬 Wi-Fi와 호환되는 스마트 홈 기기.
- 열 스로틀링을 방지하기 위한 액티브 냉각.

## 아키텍처

1. Home Assistant OS가 기기와 자동화를 관리합니다.
2. openWakeWord가 웨이크 워드를 로컬에서 감지합니다.
3. Whisper가 Wyoming을 통해 현재 활성화된 언어의 음성 명령을 텍스트로 변환합니다.
4. 인텐트 처리기가 스마트 홈 명령을 로컬에서 실행합니다.
5. Piper가 카탈루냐어로 응답을 음성 합성합니다.
6. Ollama는 데이터를 인터넷으로 보내지 않고 일반적인 질문에 답합니다.
7. 고급 AI가 필요한 명시적 요청만 클라우드 AI로 보냅니다.

## 예정된 기능

- 음성으로 조명, 콘센트, 냉난방, 블라인드 및 기타 기기 제어.
- 다국어 별칭.
- 음성으로 관리하는 타이머.
- 지역 날씨 확인.
- 음악 재생 및 제어.
- 개인정보를 보호하는 Ollama 모델 폴백.
- 목소리로 사용자 식별.
- 장기 컨텍스트 메모리.
- 클라우드 AI 모델로 선택적 전달.
- 백업 및 성능 모니터링.

## 설계 원칙

- 인터넷에 연결되지 않아도 스마트 홈 명령이 작동해야 합니다.
- 로컬 인텐트 처리기를 LLM보다 우선합니다.
- 오디오 데이터와 비공개 대화는 가능한 한 로컬에서 처리합니다.
- 클라우드 모델은 명시적으로 요청했거나 복잡한 질의에만 사용하며, 어시스턴트를 설정할 때 사용자가 명시적으로 활성화한 경우에만 사용합니다.
- 지속적인 부하에서도 온도와 지연 시간이 안정적으로 유지되어야 합니다.

## 프로젝트 상태

프로젝트는 현재 기능 백로그로 정의되어 있습니다. 사용자 스토리가 완료됨에 따라 구체적인 설정, 자동화, 배포 스크립트를 추가할 예정입니다.
