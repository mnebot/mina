## Mina ᏚᏙᎥ ᎤᏃᏴᎩ

**Mina** ᏚᏙᎥ ᎠᏓᏅᏖᏗ German ᎤᏃᏴᎩ *minna*, ᎤᏙᎯᏳᏗ «ᎠᏓᏅᏖᏍᏗ», «ᎠᏓᏅᏖᏍᏗ» ᎠᎴ «ᎠᏓᏅᏖᏍᏗ». ᎯᎠ ᎠᏓᏅᏖᏗ ᎤᏂᎳᏫᏍᏗ: Persian ᎦᏬᏂᎯᏍᏗ *mīnā* «ᎤᎦᎾᏍᏗ» ᎠᎴ «ᎠᏓᏅᏖᏍᏗ»; Japanese ᎦᏬᏂᎯᏍᏗ *mina* «ᏂᎦᏛ» ᎠᎴ «ᏂᎦᏛ ᎠᏓᏅᏖᏍᏗ».

ᎯᎠ ᎠᏓᏅᏖᏗ **ᎠᏓᏅᏖᏍᏗ ᎠᎴ ᎠᏂᏴᏫ** ᎠᏓᏅᏖᏗ, ᎤᏓᏅᏖᏗ ᎤᏁᎳᏅᎯ ᎤᏓᏅᏖᏗ ᏗᎦᎳᏫᏍᏗ ᎤᏙᎯᏳᏗ.

Mina ᏚᏙᎥ ᎤᏙᎯᏳᏗ ᎠᎴ ᎤᎦᎾᏍᏗ; `Mi-na` ᏔᎵ ᎤᏓᏅᏖᏗ, ᎠᎴ ᎤᏓᏅᏖᏗ ᏗᎦᎳᏫᏍᏗ ᎤᏂᎳᏫᏍᏗ ᎤᏙᎯᏳᏗ.

## ᎤᏓᏅᏖᏗ

ᎤᏓᏅᏖᏗ ᎤᏁᎳᏅᎯ, ᎤᏙᎯᏳᏗ ᎠᎴ ᎤᎦᎾᏍᏗ ᎤᏓᏅᏖᏗ ᎤᏓᏅᏖᏗ; ᎤᏓᏅᏖᏗ ᎠᏂᏴᏫ ᎤᏓᏅᏖᏗ ᎠᏓᏅᏖᏗ, cloud ᎠᏓᏅᏖᏗ ᎤᏓᏅᏖᏗ ᎠᎴ Ꮭ ᎤᏓᏅᏖᏗ.

ᎯᎠ ᎠᏓᏅᏖᏗ:

- Local processing ᎤᏓᏅᏖᏗ ᎠᎴ ᎤᏁᎳᏅᎯ.
- Ollama ᎤᏓᏅᏖᏗ local intelligence ᎤᏓᏅᏖᏗ ᎠᏓᏅᏖᏗ.
- Cloud models ᎤᏓᏅᏖᏗ ᎠᏓᏅᏖᏗ ᎠᎴ ᎤᏂᏴᏫ ᎤᏃᏴᎩ.

## Hardware

- Raspberry Pi 5 8 GB RAM ᎤᏓᏅᏖᏗ. Raspberry Pi 3B+ ᎤᏓᏅᏖᏗ ᎤᏙᎯᏳᏗ.
- NVMe SSD disk, SD card ᎤᏓᏅᏖᏗ. SD card ᎤᏓᏅᏖᏗ ᎤᏙᎯᏳᏗ.
- USB microphone ᎠᎴ speaker ᏔᎵ ᎤᏓᏅᏖᏗ.
- Zigbee, Matter, Philips Hue ᎠᎴ local Wi-Fi ᎤᏓᏅᏖᏗ.
- Active cooling ᎤᏓᏅᏖᏗ ᎤᏙᎯᏳᏗ.
