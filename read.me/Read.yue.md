# 多語言智能家居助手


**其他版本：** [粵語](Read.yue.md) · [Català](Read.ca.md) · [English](Read.en.md) · [Español](Read.es.md) · [Français](Read.fr.md) · [Deutsch](Read.de.md) · [Italiano](Read.it.md) · [Português](Read.pt.md) · [Nederlands](Read.nl.md)

呢個項目介紹點樣喺 Raspberry Pi 上部署本地智能家居生態系統，同埋多語言語音助手。

## Mina 個名嘅由來

**Mina** 源自古日耳曼語詞根 *minna*，意思係「記憶」、「關愛」或者「回憶」。呢個名亦喺其他語言出現：喺波斯語入面，*mīnā* 同「光」或者「藍色玻璃」有關；喺日語入面，*mina* 解作「大家」或者「所有人一齊」。

呢啲意思象徵**共同記憶同社群**，亦同一個陪伴同支援家庭日常生活嘅助手所重視嘅價值一致。

講到發音，Mina 聽落柔和又清晰，分音節讀係 `Mi-na`，喺屋企環境入面同常用詞混淆嘅機會好低。

## 目標

建立一個注重私隱、可靠又反應快嘅智能家居系統，等使用者可以用語音指令控制屋企設備，唔使一定依賴雲端服務。

架構包括：

- 喺本地處理智能家居指令，保障私隱。
- 用 Ollama 喺本地處理一般問題。
- 用雲端模型回答複雜問題同提供最新資訊。

## 硬件

- 建議用有 8 GB RAM 嘅 Raspberry Pi 5。相容性有限，最低支援到 Raspberry Pi 3B+。
- 用 NVMe SSD，唔用 SD 卡。對 SD 卡嘅支援有限。
- 雙向 USB 麥克風同喇叭。
- 支援 Zigbee、Matter、Philips Hue 或本地 Wi-Fi 嘅智能家居設備。
- 主動散熱，避免過熱降頻。

## 架構

1. Home Assistant OS 管理設備同自動化。
2. openWakeWord 喺本地偵測喚醒詞。
3. Whisper 透過 Wyoming 將語音指令轉寫成目前啟用語言嘅文字。
4. 意圖處理器喺本地執行智能家居指令。
5. Piper 用加泰羅尼亞語合成語音回覆。
6. Ollama 處理一般問題，唔會將資料傳去互聯網。
7. 只有明確需要進階 AI 嘅查詢先會交畀雲端 AI。

## 計劃功能

- 用語音控制燈、插座、冷氣、百葉簾同其他設備。
- 多語言別名。
- 用語音管理計時器。
- 查詢本地天氣。
- 播放同控制音樂。
- 私隱優先地轉用 Ollama 模型。
- 透過聲音辨認使用者。
- 長期上下文記憶。
- 可選擇交畀雲端 AI 模型處理。
- 備份同效能監察。

## 設計原則

- 冇互聯網連線都要可以執行智能家居指令。
- 本地意圖處理器優先過 LLM。
- 音訊資料同私人對話盡量喺本地處理。
- 雲端模型只會用喺明確提出或者較複雜嘅查詢，而且只會喺使用者設定助手時明確選擇啟用之後先使用。
- 系統喺持續負載之下要保持溫度同延遲穩定。

## 項目狀態

目前項目以功能待辦清單形式定義。具體設定、自動化同部署腳本會隨住使用者故事逐步完成而加入。
