# 多语言智能家居助手


**阅读版本：** [简体中文](Read.zh-CN.md) · [Català](Read.ca.md) · [English](Read.en.md) · [Español](Read.es.md) · [Français](Read.fr.md) · [Deutsch](Read.de.md) · [Italiano](Read.it.md) · [Português](Read.pt.md) · [Nederlands](Read.nl.md)

本项目介绍如何在 Raspberry Pi 上部署本地智能家居生态系统，并配备多语言语音助手。

## Mina 名称的由来

**Mina** 源自古日耳曼语词根 *minna*，意为“记忆”“关爱”或“回忆”。这个名字也出现在其他语言中：在波斯语中，*mīnā* 与“光”或“蓝色玻璃”有关；在日语中，*mina* 意为“大家”或“所有人聚在一起”。

这些含义象征着**共同记忆与社区**，与陪伴并支持家庭日常生活的助手所秉持的价值观相契合。

从发音上看，Mina 听起来柔和而清晰，按音节读作 `Mi-na`，在家庭环境中与常用词混淆的可能性较低。

## 目标

打造一个私密、可靠且响应迅速的智能家居系统，让用户能够通过语音命令控制家中设备，而无需依赖云服务。

架构组合了：

- 本地处理智能家居命令并保护隐私。
- 使用 Ollama 在本地处理一般问题。
- 使用云端模型回答复杂问题并提供最新信息。

## 硬件

- 推荐使用配备 8 GB RAM 的 Raspberry Pi 5。兼容性有限，最低可到 Raspberry Pi 3B+。
- 使用 NVMe SSD，不使用 SD 卡。对 SD 卡的支持有限。
- 双向 USB 麦克风和扬声器。
- 兼容 Zigbee、Matter、Philips Hue 或本地 Wi-Fi 的智能家居设备。
- 主动散热，避免热降频。

## 架构

1. Home Assistant OS 管理设备和自动化。
2. openWakeWord 在本地检测唤醒词。
3. Whisper 通过 Wyoming 将语音命令转写为当前启用语言的文本。
4. 意图处理器在本地执行智能家居命令。
5. Piper 用加泰罗尼亚语合成语音回复。
6. Ollama 在不向互联网发送数据的情况下处理一般问题。
7. 只有明确需要高级 AI 的请求才会发送给云端 AI。

## 计划功能

- 通过语音控制灯光、插座、空调、百叶窗及其他设备。
- 多语言别名。
- 通过语音管理计时器。
- 查询本地天气。
- 播放和控制音乐。
- 私密回退至 Ollama 模型。
- 通过声音识别说话者。
- 长期上下文记忆。
- 可选地转交给云端 AI 模型。
- 备份和性能监控。

## 设计原则

- 智能家居命令必须在没有互联网连接时也能运行。
- 本地意图处理器优先于 LLM。
- 音频数据和私人对话应优先在本地处理。
- 云端模型仅用于明确提出或较复杂的请求，而且只有在用户配置助手时明确选择启用的情况下才会使用。
- 系统在持续负载下应保持稳定的温度和延迟。

## 项目状态

本项目目前以功能待办事项清单的形式定义。具体配置、自动化和部署脚本将随着用户故事逐步完成而陆续添加。
