# ผู้ช่วยบ้านอัจฉริยะหลายภาษา


**อ่านภาษา:** [ไทย](Read.th.md) · [Català](Read.ca.md) · [English](Read.en.md) · [Español](Read.es.md) · [Français](Read.fr.md) · [Deutsch](Read.de.md) · [Italiano](Read.it.md) · [Português](Read.pt.md) · [Nederlands](Read.nl.md)

โปรเจกต์นี้อธิบายการติดตั้งระบบนิเวศบ้านอัจฉริยะแบบภายในเครือข่ายบน Raspberry Pi พร้อมผู้ช่วยเสียงหลายภาษา

## ที่มาของชื่อ Mina

**Mina** มีรากศัพท์จากคำ *minna* ในภาษาเจอร์แมนิกโบราณ ซึ่งหมายถึง “ความทรงจำ” “ความรักใคร่” หรือ “การระลึกถึง” ชื่อนี้ยังปรากฏในภาษาอื่นด้วย ในภาษาเปอร์เซีย *mīnā* เกี่ยวข้องกับ “แสง” หรือ “แก้วสีน้ำเงิน” ส่วนในภาษาญี่ปุ่น *mina* หมายถึง “ทุกคน” หรือ “ทุกคนร่วมกัน”

ความหมายเหล่านี้สื่อถึง**ความทรงจำร่วมกันและชุมชน** ซึ่งสอดคล้องกับคุณค่าของผู้ช่วยที่อยู่เคียงข้างและสนับสนุนชีวิตประจำวันในบ้าน

ในแง่เสียง Mina ฟังนุ่มนวลแต่ชัดเจน ออกเสียงแยกพยางค์เป็น `Mi-na` และมีโอกาสสับสนกับคำที่ใช้กันทั่วไปในบ้านน้อย

## เป้าหมาย

สร้างระบบบ้านอัจฉริยะที่เป็นส่วนตัว เชื่อถือได้ และตอบสนองรวดเร็ว ช่วยให้ควบคุมอุปกรณ์ภายในบ้านด้วยคำสั่งเสียงได้โดยไม่จำเป็นต้องพึ่งพาบริการคลาวด์

สถาปัตยกรรมประกอบด้วย:

- ประมวลผลคำสั่งบ้านอัจฉริยะภายในระบบและรักษาความเป็นส่วนตัว
- ใช้ Ollama ประมวลผลคำถามทั่วไปภายในระบบ
- ใช้โมเดลคลาวด์สำหรับคำถามซับซ้อนและข้อมูลล่าสุด

## ฮาร์ดแวร์

- แนะนำ Raspberry Pi 5 ที่มี RAM 8 GB โดยรองรับแบบจำกัดลงไปจนถึง Raspberry Pi 3B+
- ใช้ SSD NVMe โดยไม่ใช้การ์ด SD การรองรับการ์ด SD มีจำกัด
- ไมโครโฟนและลำโพง USB แบบสองทิศทาง
- อุปกรณ์บ้านอัจฉริยะที่รองรับ Zigbee, Matter, Philips Hue หรือ Wi-Fi ภายในระบบ
- ระบบระบายความร้อนแบบแอ็กทีฟเพื่อป้องกันการลดความเร็วเนื่องจากความร้อน

## สถาปัตยกรรม

1. Home Assistant OS จัดการอุปกรณ์และระบบอัตโนมัติ
2. openWakeWord ตรวจจับคำปลุกภายในระบบ
3. Whisper ถอดเสียงคำสั่งเป็นข้อความในภาษาที่เปิดใช้อยู่ผ่าน Wyoming
4. ตัวประมวลผลเจตนาทำงานตามคำสั่งบ้านอัจฉริยะภายในระบบ
5. Piper สังเคราะห์เสียงตอบกลับเป็นภาษาคาตาลัน
6. Ollama ตอบคำถามทั่วไปโดยไม่ส่งข้อมูลออกไปยังอินเทอร์เน็ต
7. ส่งเฉพาะคำถามที่ระบุชัดเจนว่าต้องใช้ AI ขั้นสูงไปยัง AI บนคลาวด์

## ฟีเจอร์ที่วางแผนไว้

- สั่งงานไฟ ปลั๊ก เครื่องปรับอากาศ มู่ลี่ และอุปกรณ์อื่นด้วยเสียง
- ชื่อเรียกแทนหลายภาษา
- ตั้งเวลาและจัดการตัวจับเวลาด้วยเสียง
- สอบถามสภาพอากาศในพื้นที่
- เล่นและควบคุมเพลง
- เปลี่ยนไปใช้โมเดล Ollama แบบรักษาความเป็นส่วนตัว
- จดจำผู้พูดจากเสียง
- จดจำบริบทระยะยาว
- เลือกส่งต่อคำถามไปยังโมเดล AI บนคลาวด์ได้
- สำรองข้อมูลและตรวจสอบประสิทธิภาพ

## หลักการออกแบบ

- คำสั่งบ้านอัจฉริยะต้องทำงานได้แม้ไม่มีการเชื่อมต่ออินเทอร์เน็ต
- ให้ตัวประมวลผลเจตนาภายในระบบทำงานก่อน LLM
- ประมวลผลข้อมูลเสียงและบทสนทนาส่วนตัวภายในระบบเป็นหลัก
- ใช้โมเดลคลาวด์เฉพาะกับคำถามที่ระบุชัดเจนหรือซับซ้อน และใช้ได้ต่อเมื่อผู้ใช้เปิดใช้งานอย่างชัดเจนขณะตั้งค่าผู้ช่วย
- ระบบต้องรักษาอุณหภูมิและเวลาแฝงให้คงที่ภายใต้ภาระงานต่อเนื่อง

## สถานะโปรเจกต์

ขณะนี้โปรเจกต์กำหนดไว้เป็นรายการงานด้านฟังก์ชัน โดยจะเพิ่มการตั้งค่าเฉพาะ ระบบอัตโนมัติ และสคริปต์ติดตั้งใช้งานเมื่อเรื่องราวผู้ใช้เสร็จสมบูรณ์
